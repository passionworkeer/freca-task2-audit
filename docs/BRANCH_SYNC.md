# Task2 分支同步边界

## 已确认的执行基线

组织仓库的 `Task2-agent-pipeline` 是唯一可执行的实验基线。它对应当前 `freca` 架构，覆盖 DOCX、XLSX 和 PDF 的解析、持久化 chunk、索引、审计与最终 verdict 产物。

## 不执行整体合并的原因

组织仓库的 `Task2` 是 2026-07-25 的农场案例实现，`Task2-agent-pipeline` 是另一条独立历史。两条分支没有 merge base，不能用 Git merge 或 rebase 当作常规同步操作。

`Task2` 中的农场解析、chunk cache 或检索实现仅作为能力参考。本次没有迁入其中代码：当前 `freca` 已具备本轮评估所需的输入、解析与检索链路。

## 后续迁移规则

任何未来的选择性迁移必须：

1. 只迁入一个可明确说明的能力；
2. 转换到既有 `freca` 输入/输出契约，不新增第二套 `backend/` 入口或运行状态；
3. 先新增针对该兼容边界的失败测试，再写实现；
4. 通过全量测试后才进入实验基线。
